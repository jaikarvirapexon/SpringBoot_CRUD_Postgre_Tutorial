## Numbering

- Epics: `<EPIC>` (3-letter uppercase code, e.g. `CHK`).
- Stories: `<EPIC>-<NN>`.
- Tasks: `<EPIC>-<NN>.<MM>`.
- Test cases: `<EPIC>-<NN>-TC-<MM>`.
